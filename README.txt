FiveM Enhanced Crash Map

Open index.html and the map opens immediately in full screen.

Controls:
- Drag to move
- Mouse wheel to zoom
- Click Add zones: OFF to turn editor on
- Click the map to create a red crash circle
- Click an existing circle and type DELETE to remove it

To publish:
Upload all four files to GitHub Pages, Netlify, or your web hosting:
index.html
style.css
script.js
map.png
